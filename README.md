# PrimebAll

ケースとQMK / Remapファームウェアの配布データです。

[v2.8のダウンロード](https://github.com/Alco-1129/PrimebAll/releases/tag/v2.8)

- USB接続側がセントラル、TRRSで左右を接続
- 接続側ごとに独立して保存する10レイヤー（0～9）
- SC Holdを押している間だけ、方向固定トラックボールスクロール
- 12カウント・1.5倍の優勢方向を判定し、縦か横の一方だけを出力。180msの停止で再判定
- Remap独自キーでCPI±、スクロール量±、オートマウスON/OFFを変更
- 左OLED：大型レイヤー数字とUSB接続側
- 右OLED：移動量・CPI・SCR ON/OFF・方向/分母・AM状態・複数の押下キー
- 47灯・50パターン

ケースを含む一式は `PrimebAll_case_firmware_v2_8.zip`、ファームウェアのみは `PrimebAll_firmware_v2_8.zip` を選んでください。
通常版とRemap版のUF2、ソース、Remap定義、使い方を含みます。両側へ同じ版を書き込んでください。
初期配列は共通です。左右それぞれをUSB接続してRemapで個別に変更できます。
使い方は一式ZIP内の `firmware/使い方.txt`、ファームウェアZIP内の `使い方.txt` を参照してください。
v2.7の保存配列は維持できます。新しい定義を読み込み、追加の独自キーをRemapで配置してください。

ケースはv2.6形状です。トップとボトムの2部品構成、テンティングなし、PETG / A1 mini対応。
必須印刷数14個/セット。STL、3MF、STEP、Blender、フォームと再生成ソースを含みます。
STEPは面分割近似を含むため、アルミ加工前に加工者の形状確認を受けてください。
ビルドとソフトウェア試験済みです。実機動作・嵌合・ガスケット・接着強度は試作で確認してください。
